# トレファクさがし帳

トレファクオンライン（trefac.jp）のメンズ古着（男女兼用を含む）を、ブランド・商品名で探せる個人用の検索サイト。
非公式で、トレジャー・ファクトリーとは関係ありません。

- `scripts/build.py`：データを集めて `public/data/` に書き出す（標準ライブラリだけ）。2 秒に 1 回まで（1 秒おきに 1 時間取ると 429 で断られた）
- `public/`：公開するページ。検索はブラウザの中で動く（`search.js`）
- `.github/workflows/update.yml`：毎朝 7:00（日本時間）に取り直してコミットする

## データの取り方

トレファクの一覧は 1 つの条件で 9,990 件までしか見られないので、「カテゴリ × 状態」に分けて取る。
毎朝は新着順（入荷と値下げが混ざった順）で、新しい商品も値段の変化もないページまでめくる。
そのうえで 300 ページぶん、全部めくり直す組を回して売れた商品を消す（1 週間ほどで一回り）。

## 手元で見る

```
python3 -m http.server 8769 -d public
```
